# Data Menu Engine V1.0

A simple Python console application that simulates a mobile network data subscription system.

## Features

- Purchase Daily, Weekly, and Monthly data plans
- Check airtime balance
- Automatically deduct the cost of purchased plans
- Save balance using file handling
- Load balance when the program starts
- Save purchase history
- View purchase history
- Handle invalid menu input using exception handling

## Technologies Used

- Python 3
- Functions
- Dictionaries
- Nested Dictionaries
- Loops
- Exception Handling
- File Handling

## Project Files

- `Data Menu Engine V1.0.py` - Main application
- `balance.txt` - Stores the current balance
- `history.txt` - Stores purchase history
